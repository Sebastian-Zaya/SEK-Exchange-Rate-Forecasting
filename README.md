Forecasting SEK/USD Under Geopolitical & Supply Chain Shocks

A MATLAB implementation of an Autoregressive Distributed Lag model with Bayesian Variable Selection (ADL-BVS) to forecast SEK/USD depreciation rates across 3-, 12-, and 24-month horizons using macroeconomic fundamentals and global shock indices (GPR and GSCPI).   

main_paper.m — MATLAB code for the BVS Gibbs sampler and forecasting evaluation.   
Data_Sweden.xlsx — Monthly macroeconomic and external shock dataset (1998–2026).   
forecasting.SEK.pdf — Full research paper and empirical results.
